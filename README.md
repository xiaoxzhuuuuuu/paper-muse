# 纸间灵感 · 面试体验版

AI辅助制作配色与笔记模板。部署配置已包含在 render.yaml 中。

## 发布
使用 Render Blueprint 连接本仓库，填写 DEEPSEEK_API_KEY 和 DEMO_ACCESS_CODE。
选择免费服务。密钥只填写在 Render 设置中，不提交到代码。

## 使用
打开部署成功后的 HTTPS 网址，点击“填写体验码”，再输入心情或作品描述生成。
API由作者提供。体验码使用英文字母和数字，切勿使用API密钥作为体验码。

## 演示限制
单进程最多30次模型请求（并非30次生成，也非金额硬上限）；服务重启或休眠后会重置。
每个模型请求内部可能有额外联网检索费用。实际费用以模型平台账单为准。
每IP每小时最多20次生成/上传请求；单次仅允许一个生成任务。
免费Render闲置15分钟可能休眠，重新打开约需一分钟；生成本身还需要等待。
运行期间上传的参考图、缓存图片和缓存方案不会长期保存，重启可能丢失。
请及时下载作品；需要重新使用时可重新生成或重新上传。
这是少量面试试用版本，不适合开放给大量用户。

## 停止体验
在Render控制台暂停服务，或者修改DEMO_ACCESS_CODE使旧体验码失效。
需要恢复调用次数时先核对DeepSeek账单，再重启服务。

## 核验状态
本地接口和浏览器模拟流程已检查；线上部署、真实额度及实际访问速度需发布后验证。
